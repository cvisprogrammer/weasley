Brii Inline commands · experiment

Execute //instruction// on closing slashes, or //instruction with Enter. //...// continues a sentence. Shift+Enter inserts a newline; Escape cancels.

Commands beside existing text rewrite that whole line; commands on their own line insert. //...// only continues.

Your instruction, target line and nearby editor text are sent to OpenAI. In Gmail, commands also include up to 8,000 characters of the visible email thread or your reply’s quoted original. Expand quoted text first if it is hidden. The API key stays in your local bridge. API usage costs apply. Nothing is automatically sent or booked.
