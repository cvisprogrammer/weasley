Connect Google once

The extension needs a public Google OAuth client ID for this extension ID:

  1. In Google Cloud Console, choose/create a project and enable the Gmail API.
  2. Configure Google Auth Platform / the OAuth consent screen. For a personal prototype, keep the app in Testing and add your Google account as a test user. Add the restricted scope https://www.googleapis.com/auth/gmail.readonly.
  3. Create an OAuth client with application type Chrome Extension and the extension ID shown above as its Application ID. No client secret is used.
  4. Paste the public client ID below. Download the generated manifest, replace manifest.json in the same existing extension folder, then click Reload in chrome://extensions. Reopen this inbox.

Public distribution may require Google's restricted-scope verification. Testing/authorization rules are controlled by Google; follow the current console guidance. Never paste a client secret or access token here.

Privacy and account settings

We request read-only Gmail access. We never send, delete, archive, mark read, or apply Gmail labels. The model receives bounded thread text locally. HTML is converted to text without loading images, links or attachments. There is no developer backend or telemetry.

Gmail badges contain a supporting quote in browser-session memory and expire from view after 15 minutes or observed row changes. Dismissed thread fingerprints are stored locally without subjects or bodies. Disconnect clears those records, visible results and the local model. If revocation fails, remove access in Google account connections.

Aliases are used only in the current scan; they are not saved.

Each scan checks up to 20 Primary inbox threads. Older or unscanned mail is unknown, not cleared. Flags indicate a request, not that the sender is trustworthy. Model decisions can be wrong.
