Brii Inline commands · experiment

Shift+Enter inserts a newline; Escape cancels.

Commands beside existing text rewrite that whole line; commands on their own line insert. The continuation instruction ... only continues.

Your instruction, target line and nearby editor text are sent to OpenAI. When page/thread context is enabled, commands also include up to 8,000 characters from the visible Gmail thread or current webpage. Context includes its domain (not the full URL) and visible text near your editor, article/main content, or a filtered page fallback. This text is sent only when a command runs. Expand quoted text first if it is hidden. The API key stays in your local bridge. API usage costs apply. Nothing is automatically sent or booked.
